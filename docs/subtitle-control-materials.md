## Ручная разметка

Для каждого образца перед сравнительным прогоном нужно выбрать три участка по 20–30 секунд:

1. чистая непрерывная речь;
2. речь на фоне музыки или шума;
3. участок с именами, числами, англицизмами либо длинными словами.

В эталоне фиксируются точный текст, границы целых слов и отдельно спорные места. Полный текст ролика в репозиторий не добавляется. Локальная разметка хранится в `storage/asr-evaluation/`, который уже исключён правилом `storage/`.

## Сравниваемые конфигурации

- текущий `whisper.cpp` multilingual small;
- WhisperX 3.8.6 / faster-whisper с `large-v3-turbo`, CUDA и `float16`;
- тот же новый стек с CPU fallback только для проверки управляемой деградации.

Метрики: время обработки, пиковая VRAM, наличие служебных токенов, ошибки целых слов и абсолютная ошибка начала/конца слова.

## Результат первого GPU smoke-прогона

Дата: 17 сентября 2026 года. Конфигурация: WhisperX 3.8.6, `large-v3-turbo`, CUDA 12.8, `float16`, batch size 8, RTX 4080.

| Образец | Время | Сегментов | Целых слов | Сегментов без alignment |
| --- | ---: | ---: | ---: | ---: |
| `tools` | 114,190 с вместе с первичной загрузкой моделей | 7 | 77 | 0 |
| `clones` | 14,582 с | 6 | 79 | 0 |
| `sith` | 14,553 с | 1 | 84 | 0 |

Во всех трёх результатах отсутствуют служебные timestamp-токены и части tokenizer. Слова `огнетушитель`, `переметнулась` и `солдат-клонов` сохранены целиком. Для объективной оценки WER и ошибки границ всё ещё требуется ручная эталонная разметка выбранных участков.

TorchCodec предупреждает о несовместимости встроенного декодера с FFmpeg 8, но этот путь не используется: WhisperX успешно получает предварительно загруженный WAV и завершает ASR с alignment. Предупреждение не считается блокирующим, пока diarization не входит в объём эпика.

Полный 599,999-секундный образец `tools` после заполнения кэша обработан за 22,601 секунды. Получено 136 сегментов и 1187 целых слов; сегментов без alignment, служебных токенов и пересечений словесных таймкодов не обнаружено. Для интервала 60–90 секунд компоновщик сформировал 39 ASS-событий максимум по два слова.
