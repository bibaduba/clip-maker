# Локальная проверка YouTube → русская расшифровка

Этот этап — CLI-прототип обработки, ещё не очередь сайта. Он скачивает только начальный аудиофрагмент ролика, превращает его в WAV и распознаёт локально. Видео для монтажа, ИИ-выбор фрагментов, постоянная очередь и авторизация будут подключены следующими этапами. Платный AI API здесь не используется.

## Окружение

Проверено устройство arm64, MacBookPro18,3, 16 GiB RAM; до установки оставалось около 62 GiB диска. Установлены yt-dlp и whisper.cpp через Homebrew; FFmpeg уже присутствовал. Homebrew также обновил свои зависимости и сохранил резервные копии заменённых Python-ссылок в стандартном кеше Homebrew.

```sh
brew install yt-dlp whisper-cpp
npm install
```

Для русского требуется многоязычная модель `small`, не `small.en`. Модель скачана в `storage/models/ggml-small.bin` (~466 MiB). Для повторной установки:

```sh
mkdir -p storage/models
curl -fL --retry 2 -o storage/models/ggml-small.bin.part https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-small.bin
mv storage/models/ggml-small.bin.part storage/models/ggml-small.bin
```

Переносить `.part` в `.bin` только после успешной загрузки. Источники: [whisper.cpp](https://github.com/ggml-org/whisper.cpp), [официальный скрипт моделей](https://github.com/ggml-org/whisper.cpp/blob/master/models/download-ggml-model.sh).

## Запуск

```sh
npm run media:benchmark -- 'https://www.youtube.com/watch?v=34HF78uOe1k' 180
```

Последний аргумент — 10–180 секунд от начала, по умолчанию 180. Принимаются завершённые видео до 120 минут. Настоящие эфиры и премьеры отклоняются. Timestamp в ссылке пока игнорируется. Допускается только YouTube; адрес нормализуется до video ID перед вызовом загрузчика.

Все результаты в `storage/benchmarks/<videoId>-<timestamp>/`:

- `source.json` — название, ID и длительность исходного ролика;
- `source.*` — скачанный аудиофрагмент;
- `audio.wav` — PCM16 mono 16 kHz;
- `whisper.json` — оригинальный результат движка;
- `transcript.json` — русские сегменты с границами в секундах;
- `transcript.txt` — текст для ручной проверки;
- `report.json` — время распознавания, отношение к длительности, SHA-256 модели;
- `status.json` — этап либо ошибка.

Всё содержимое storage исключено из git и не выдаётся через public/. Наличие текста ещё не подтверждает точность — перед выбором модели нужно прослушать фрагмент и проверить ошибки, паузы, имена и таймкоды. Это фразовые метки, не точная разметка каждого слова.

`WHISPER_MODEL` и `WHISPER_CLI` можно задать переменными окружения. Для этого CLI `.env` автоматически не загружается. GPU включён штатно в whisper.cpp; фактическое использование Metal проверяется по логам.

## Ограничения и сбои

Один тест одновременно: `storage/benchmark.lock`. Ctrl+C отменяет текущий процесс и снимает lock при нормальном завершении. После аварийного выключения lock может остаться: убедиться, что процесса с указанным PID больше нет, затем удалить только этот файл вручную. Незавершённые результаты не используются как готовая расшифровка; каждый запуск создаёт отдельный каталог.

До запуска требуется 3 GiB свободного места; запросы ограничены временем. Загрузка секции зависит от форматов YouTube: не считать её гарантией фиксированного трафика. Эта экспериментальная команда не подходит для публичного запуска; перед production нужны контроль диска во время работы, постоянная очередь, восстановление и изоляция пользователей.

Тест не читает cookies браузера. Если YouTube требует вход или отклоняет запрос — возвращается ошибка. При сетевой ошибке сохраняются статус и этап; готовый report появляется только после валидного результата.

Проверки: `npm run test:media` и `npm run typecheck`.

Последний сегмент Whisper иногда выходит за конец тестового аудио. Допускается до 5 секунд только для последнего сегмента: конец ограничивается длительностью WAV и сегмент получает `truncated: true`. Такой фрагмент нельзя считать законченной фразой при будущем выборе клипов. Другие некорректные интервалы отклоняются.

## Результат теста 2026-09-16

YouTube ID `34HF78uOe1k`, исходник 15 мин 11 с, первые 179.99 с аудио. Модель small, whisper.cpp 1.9.4, Apple M1 Pro / Metal. Распознавание заняло 11.10 с (RTF 0.062, примерно в 16.2 раза быстрее воспроизведения). Полный запуск с сетью: 104.7 с. Получено 21 сегментов. Полный проход завершён после исправления последней обрезанной фразы.

Первый холодный запуск дополнительно компилировал Metal-библиотеки около 22 с; повторный запуск использовал кеш. Это замер одного чисто записанного разговорного ролика, не прогноз для шумных стримов. Качество не проверено по эталонной расшифровке; small пока кандидат, не окончательный выбор.

Отчёт: `storage/benchmarks/34HF78uOe1k-1789524727895/report.json`; текст: соседний `transcript.txt`. 8 автоматических тестов и TypeScript прошли.
