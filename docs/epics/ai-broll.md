# BROLL-01 — AI B-roll

Статус: первый сквозной вариант реализован; для включения требуется ключ Pexels.

## Реализовано

- Доступность `kimi-k3` подтверждена через официальный `/v1/models` текущего аккаунта.
- Ключ читается только из `KIMI_API_KEY` на сервере и не передаётся в браузер.
- Kimi получает только расшифровку выбранного клипа и его границы.
- Расшифровка явно рассматривается как недоверенные данные.
- План содержит до четырёх непересекающихся вставок длительностью 2–7 секунд.
- Для каждой вставки возвращаются таймкоды, запрос для стоковой библиотеки, английский промпт генерации, причина и режим `stock`/`generate`.
- Ответ проверяется локально: интервалы, размеры строк, режим и пересечения нельзя доверить модели.
- Ошибки API не раскрывают ключ или полный ответ провайдера.

- Добавлен адаптер Pexels Video API: поиск по запросу Kimi, ориентации и минимальной длительности.
- Загрузка ограничена доверенными HTTPS-доменами и размером 250 МБ.
- Для каждого материала сохраняются автор, страница источника и `Pexels License`.
- Добавлен отдельный FFmpeg-компоновщик полноэкранных вставок с сохранением исходного звука.
- Поддерживаются полноэкранные вставки, нижняя половина кадра и картинка-в-картинке.
- Pexels используется и как видеотека, и как фототека; изображения получают плавный zoom/pan.
- Вставки появляются и исчезают через короткий alpha-переход, а субтитры накладываются последним слоем поверх монтажа.
- Настройка AI B-roll доступна в форме, когда одновременно настроены Kimi и Pexels.
- Kimi составляет план только для уже выбранного клипа; Pexels подбирает лицензированный материал, после чего FFmpeg монтирует его по таймкодам.
- Субтитры накладываются последним слоем и остаются видимыми поверх B-roll.
- Ошибка Kimi, Pexels или отсутствие подходящего материала не останавливает проект: клип создаётся обычным способом, а причина сохраняется в `broll-manifest.json`.
- Для фактического поиска требуется бесплатный `PEXELS_API_KEY`.

## Следующий этап

- добавить предпросмотр, замену и отключение каждой вставки;
- затем подключить отдельный генератор для запросов с режимом `generate`.

Kimi K3 является языковой моделью и сам видеофайлы не генерирует. Его роль здесь — понять речь, выбрать уместный момент и сформировать точный поисковый либо генеративный запрос.
