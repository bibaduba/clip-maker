# Отбор, просмотр и монтаж по расшифровке

Статус: первая версия реализована, ожидает пользовательского прогона. Сборка и тесты не запускались по просьбе владельца.

## Найденные моменты до рендера

После расшифровки worker сохраняет расширенный пул кандидатов и переводит проект в состояние `review`. На странице проекта можно посмотреть исходник с таймкода каждого кандидата, увидеть объяснение, выбрать моменты, заменить выбранный другим кандидатом и поправить границы в пределах 20 секунд. Подтверждение сохраняет выбор и снова ставит проект в очередь на рендер. При повторном запуске утверждённый выбор читается с диска.

## Анализ кадров

Если задан `KIMI_API_KEY`, для восьми кандидатов по умолчанию извлекаются два кадра. Половина визуального бюджета достаётся самым сильным текстовым кандидатам, остальные распределяются по времени видео, чтобы длинный исходник не оценивался только в начале. Мультимодальная модель `kimi-k2.5` описывает видимое и слегка уточняет оценку. Лимит регулируется `MEDIA_VISUAL_MAX_CANDIDATES`, модель — `KIMI_VISION_MODEL`. Ошибка визуального API не останавливает обработку.

Дополнительный разреженный проход просматривает до восьми окон по всей длительности исходника вне уже выбранных речевых фрагментов. При явно видимом событии (оценка от 80) он добавляет отдельный кандидат на ручную проверку; такой кандидат может быть без субтитров, если в окне нет речи. Это не покадровый поиск: короткие события между взятыми кадрами он может пропустить. Ошибка API не прерывает генерацию.

## Монтаж по расшифровке

Редактор клипа показывает строки распознавания и позволяет отметить фразы на удаление. После рендера FFmpeg вырезает соответствующие интервалы из готового видео и звука. Выбор строк сохраняется в базе и применяется при следующем редактировании. Поле исправления текста субтитров остаётся отдельным от удаления фраз.
