# CAPTION-02 — Динамические эффекты субтитров

Статус: реализовано, ожидает ручной прогон.

## Возможности

- Пословная подсветка: ASS karaoke timing последовательно активирует слова внутри текущей фразы.
- Ключевые слова: длинные смысловые слова и числа получают контрастный цвет, отличный от основного.
- Эмодзи: к распознанным темам добавляется не более одного контекстного эмодзи на фразу.
- Автоцензор: мат скрывается в тексте, а соответствующий интервал аудио приглушается по таймкодам WhisperX.

## Настройки проекта

Все четыре возможности включаются независимо, сохраняются в SQLite и передаются в повторную генерацию. Для старых проектов включена только пословная подсветка.

## Ограничения

- Точность автоцензора зависит от пословных таймкодов WhisperX.
- Эмодзи добавляются по локальному словарю тем, без внешнего AI-запроса.
- Автоцензор использует приглушение звука, без звукового сигнала.

## Ручная проверка

Создать короткий клип со всеми четырьмя настройками и проверить последовательность подсветки, цвет ключевых слов, уместность эмодзи и совпадение приглушения с речью.
