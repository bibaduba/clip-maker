# OUTPUT-01 — Формат и длительность клипов

Статус: реализовано, ожидает ручной прогон форматов.

## Результат

Пользователь до создания проекта выбирает соотношение сторон (`9:16`, `1:1`, `4:5`, `16:9`) и диапазон длительности (`20–30`, `30–60`, `60–90` секунд). Настройки сохраняются в проекте, ограничивают подбор моментов и определяют разрешение экспорта.

## Задачи

- Сохранить параметры в SQLite с совместимыми значениями по умолчанию для старых проектов.
- Валидировать параметры в API и показывать их в форме.
- Ограничить кандидатные интервалы выбранной длительностью.
- Рендерить `720×1280`, `1080×1080`, `864×1080` или `1280×720`.
- Использовать AI-ведение лица для `9:16`, `1:1`, `4:5` и `16:9`, с центральным безопасным кропом при отсутствии лица.
- Адаптировать координатную систему ASS, размер текста и безопасные поля под формат.
- Добавить проверки каждого диапазона и формата.

## Приёмка

- Новый проект сохраняет выбранные параметры и возвращает их после перезапуска.
- Готовый клип соответствует выбранному диапазону и разрешению.
- Старые проекты открываются как `9:16`, `30–60 секунд`.
- Субтитры не выходят за безопасную область каждого формата.

## Реализация адаптации

- `9:16`: `720×1280`, крупные субтитры, увеличенный нижний отступ под элементы интерфейса Shorts.
- `1:1`: `1080×1080`, уменьшенный текст и безопасные поля по горизонтали и снизу.
- `4:5`: `864×1080`, портретный профиль с отдельными размером и отступами.
- `16:9`: `1280×720`, компактный текст и нижний отступ для широкого кадра.
- На Windows лицо определяется OpenCV; координаты сглаживаются, а кроп плавно следует за субъектом.
- Когда AI-кадрирование выключено и видео вписывается целиком, пользователь выбирает чёрные поля либо размытую увеличенную копию видео на фоне.
