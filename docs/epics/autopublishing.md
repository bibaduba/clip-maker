# PUBLISH-01 — автопубликация

## Реализовано: YouTube Shorts

- отдельное OAuth-подключение канала со scope `youtube.upload`;
- PKCE и проверка `state`;
- offline-доступ и зашифрованное хранение refresh token;
- отключение канала с отзывом токена;
- очередь публикаций и защита от повторной отправки одного клипа;
- заголовок, описание, приватность и отложенная публикация;
- resumable upload session YouTube с сохранением ID и ошибки;
- отображение статуса и ссылки на опубликованный ролик.

Для шифрования используется `SOCIAL_TOKEN_ENCRYPTION_KEY`; если он не задан, локальная установка использует `GOOGLE_CLIENT_SECRET`. Перед переносом приложения на сервер нужно задать отдельный стабильный случайный ключ и не менять его после подключения каналов.

Google Cloud должен иметь включённый YouTube Data API v3, а OAuth redirect URI должен включать `/api/social/youtube/callback`. Непроверенные API-проекты могут загружать видео только в приватном режиме до прохождения аудита Google.
