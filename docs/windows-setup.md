# Перенос и запуск на Windows

## Что установить

1. Node.js 22 или новее и Git.
2. FFmpeg, чтобы команды `ffmpeg` и `ffprobe` были доступны в `PATH`.
3. `yt-dlp`, доступный в `PATH`.
4. Windows-сборки whisper.cpp и llama.cpp. Добавьте каталоги с `whisper-cli.exe` и `llama-completion.exe` в `PATH` либо укажите полные пути в `.env.local`.
5. Модели `ggml-small.bin` и `Qwen3-4B-Q4_K_M.gguf` в `storage/models`, если папка `storage` не переносилась.

Создайте `.env.local` по образцу `.env.example`. Для пути с пробелами используйте обычное значение без запуска через оболочку, например `WHISPER_CLI=C:\Tools\whisper.cpp\whisper-cli.exe`.

## Видео с возрастным ограничением

Для таких роликов YouTube не отдаёт метаданные и видео анонимному `yt-dlp`. Экспортируйте cookies авторизованного аккаунта YouTube в Netscape-файл `cookies.txt`, сохраните его вне репозитория и добавьте в `.env.local`:

```ini
YTDLP_COOKIES_FILE=C:\Users\you\Documents\youtube-cookies.txt
```

Локальная альтернатива — чтение cookies прямо из браузера:

```ini
YTDLP_COOKIES_FROM_BROWSER=edge
```

Браузер иногда нужно полностью закрыть, чтобы его база cookies не была заблокирована. Экспортированный файл обычно надёжнее. Cookies дают доступ к аккаунту: не храните их в папке проекта, не коммитьте и не передавайте другим людям. После изменения `.env.local` перезапустите сервер и нажмите повторную генерацию проекта.

## Первый запуск

В PowerShell из папки проекта:

```powershell
npm install
npm run doctor
npm run dev
```

Откройте `http://localhost:3000`. Команда `doctor` только проверяет версии, исполняемые файлы и наличие моделей; видео она не обрабатывает.

## Особенности Windows

- Временные файлы создаются в системной временной папке Windows.
- Остановка обработки завершает дерево процессов через `taskkill`.
- На macOS AI-кадрирование использует Apple Vision, на Windows и Linux — OpenCV из `scripts/asr/requirements.txt`. Если лицо временно не найдено, используется безопасный центральный кроп выбранного формата.
- SQLite подходит для личного локального запуска. Для публичного сайта с несколькими одновременными пользователями нужны PostgreSQL, постоянная очередь заданий и отдельное объектное хранилище.
- При использовании Google OAuth оставьте callback `http://localhost:3000/api/auth/google/callback`. Для другого порта или домена добавьте соответствующий URI в Google Cloud.
