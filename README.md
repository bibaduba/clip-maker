# Clip Maker

Локальное веб-приложение для создания коротких вертикальных роликов из длинных YouTube-видео. Оно скачивает исходник, распознаёт русскую речь, ищет законченные моменты, формирует Shorts/Reels/TikTok-клипы и рендерит их с субтитрами, кадрированием и оформлением.

Проект рассчитан на запуск на собственном компьютере: исходные видео, модель распознавания, API-ключи, cookies YouTube, база данных и готовые клипы остаются локально.

> Это MVP для личного использования. Приложение не гарантирует «вирусность» клипа и не предназначено для обхода правил YouTube или прав владельцев контента.

## Возможности

- Создание проектов по ссылке YouTube и обработка длинных видео частями по 10 минут.
- Автоматический выбор законченных, интересных фрагментов; число клипов масштабируется по длине исходника.
- Расшифровка русской речи с пословными субтитрами, подсветкой ключевых слов, эмодзи и автоцензором.
- Шаблоны субтитров: Default, Modern, Bouncy, Mr. Beast и Business; цвета, шрифты, обводки и безопасная зона адаптируются к формату кадра.
- Форматы 9:16, 1:1, 4:5 и 16:9; AI-кадрирование, фон `cover`, чёрный или размытый фон при `fit`.
- Speaker detection/диаризация при подключении Hugging Face и поддерживаемом локальном окружении.
- AI B-roll: Kimi составляет запрос, Pexels подбирает видеоряд или изображение, которое накладывается в клип.
- ADHD-клипы: основной ролик сверху и игровое видео снизу. Игровые ролики выбираются из локальной библиотеки Minecraft/Subway Surfers.
- Водяной знак канала, избранное и отметка неинтересных клипов.
- Страница «Загруженные клипы», публикация на YouTube Shorts, статус очереди, повтор публикации, описание и хештеги.
- Автогенерация короткого описания для Shorts через Kimi и дефолтные YouTube-теги.
- Отдельный режим «Динамичный монтаж»: несколько склеек внутри одного клипа, проверка плана, акценты, выравнивание звука и повторное редактирование без потери склеек. Сейчас это экспериментальная функция — результат нужно проверять человеком.
- Ручной редактор: свободное кадрирование, текстовые плашки, положение элементов и повторный рендер.

## Что потребуется

### Обязательно

- Windows 10/11 или другая ОС, на которой доступны Node.js и FFmpeg.
- [Node.js 22+](https://nodejs.org/).
- Git.
- FFmpeg и FFprobe в `PATH` либо в локальной папке `.tools`.
- `yt-dlp` в `PATH`.
- Локальная модель распознавания речи: Whisper.cpp или WhisperX. Базовая конфигурация приведена в `.env.example`.
- Локальная LLM Qwen в формате GGUF и `llama-completion` для оценки моментов.

### Опционально

- `KIMI_API_KEY` — для AI B-roll, генерации описаний и визуального анализа кандидатов.
- `PEXELS_API_KEY` — для поиска B-roll на Pexels.
- `HUGGINGFACE_TOKEN` — для speaker detection через `pyannote/speaker-diarization-community-1`; доступ к модели необходимо принять в Hugging Face заранее.
- Google OAuth credentials — для входа через Google.
- YouTube OAuth credentials — для публикации Shorts на канал.
- Cookies YouTube в Netscape `cookies.txt` — только для роликов, которые YouTube не отдаёт анонимно. Файл содержит секреты сессии, поэтому он намеренно исключён из Git.

Подробности установки для Windows: [docs/windows-setup.md](docs/windows-setup.md). О локальном медиаконвейере: [docs/local-media.md](docs/local-media.md).

## Быстрый запуск

1. Клонируйте репозиторий и перейдите в каталог проекта:

   ```powershell
   git clone git@github.com:bibaduba/clip-maker.git
   cd clip-maker
   ```

2. Установите зависимости Node.js:

   ```powershell
   npm install
   ```

3. Создайте локальный файл настроек из примера:

   ```powershell
   Copy-Item .env.example .env.local
   ```

4. Откройте `.env.local` и задайте пути к установленным инструментам и моделям. Минимальный пример:

   ```ini
   MEDIA_STORAGE_PATH=storage
   WHISPER_CLI=whisper-cli
   WHISPER_MODEL=storage/models/ggml-small.bin
   LLAMA_CLI=llama-completion
   CLIP_LLM_MODEL=storage/models/Qwen3-4B-Q4_K_M.gguf
   ```

5. Проверьте окружение:

   ```powershell
   npm run doctor
   ```

6. Запустите сайт:

   ```powershell
   npm run dev
   ```

   Откройте [http://localhost:3000](http://localhost:3000).

При первом запуске база и проекты появятся в `storage/`. Эта папка не попадает в Git: в ней могут быть большие модели, скачанные исходники, клипы, SQLite-база и персональные данные.

## Настройка API и публикации

Переменные задаются только в `.env.local`, который не публикуется.

| Возможность | Нужные переменные |
| --- | --- |
| B-roll и AI-описания | `KIMI_API_KEY`, `PEXELS_API_KEY` |
| Speaker detection | `HUGGINGFACE_TOKEN` |
| Google-вход | `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET` |
| YouTube-ролики с возрастным ограничением | `YTDLP_COOKIES_FILE` или `YTDLP_COOKIES_FROM_BROWSER` |
| YouTube-публикация | Настраивается в интерфейсе через OAuth; секреты OAuth хранятся в `.env.local` |

Не добавляйте API-ключи, OAuth-секреты, cookie-файлы, модели или `storage/` в коммиты. Перед публикацией на YouTube убедитесь, что у вас есть права на исходный материал и B-roll.

## Библиотека ADHD-фонов

Игровые клипы положите в одну из папок:

```text
public/gameplay/minecraft/
public/gameplay/subway/
public/gameplay/cs/
public/gameplay/temple-run/
```

Поддерживаются MP4, WebM, MOV, MKV и AVI. Эти файлы намеренно не коммитятся: библиотека может занимать сотни мегабайт. В репозитории оставлен [README библиотеки](public/gameplay/README.md).

## Структура проекта

```text
src/app/                 Страницы Next.js и API
src/components/          Интерфейс проекта, редактор, публикация
src/server/              SQLite, авторизация, фоновые workers
scripts/media/           Скачивание, ASR, выбор моментов, рендер FFmpeg
scripts/asr/             Python-обвязка ASR/WhisperX
public/fonts/            Шрифты субтитров
public/gameplay/         Локальная библиотека ADHD-фонов (без видео в Git)
docs/                    Инструкции, продуктовые эпики и roadmap
storage/                 Локальные данные и медиа (исключены из Git)
```

## Ограничения

- Обрабатывается один проект за раз; очередь локальная.
- Качество расшифровки, выбора моментов и AI-кадрирования зависит от исходного видео и установленной модели.
- Визуальный монтаж и B-roll — помощники, а не готовая замена монтажёру. Всегда просматривайте клип перед публикацией.
- Режим динамичного монтажа пока экспериментальный.
- Для публичного развёртывания потребуются отдельные решения для очереди задач, БД, хранения медиа, защиты OAuth-токенов и лимитов пользователей. См. [docs/public-deployment.md](docs/public-deployment.md).
